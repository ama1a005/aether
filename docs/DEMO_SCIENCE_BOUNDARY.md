# Demo and Science Boundary

| Demonstration object | Scientific interpretation |
|---|---|
| Active `DEMO-PAT-*` cohort | Derived from exact PTB-XL v1.0.3 folds 1–8 records; AETHER action is derived, not an official PTB-XL endpoint; never included in causal-task statistics |
| Demo attack | AETHER deterministic tool-output manipulation illustration; not an official MCPTox score |
| Live deterministic demo pipeline | Real execution of stable AETHER software primitives; not a fresh Qwen experiment |
| Verified replay | Output previously produced by the same demo backend; visibly labelled, never presented as live |
| Research Evidence card | Read-only view of a committed experiment artifact |
| Message rescue | Supported controlled development behavior and a valid message-level intervention |
| BVP Level 1 | Accepted mediator-to-outcome causality on the positive-control development substrate |
| Internal causal result | QCI-2 supported four decision-semantic candidates; CORE-02 selected the message decision code and a receiver-head comparator. This remains separate from the presentation cohort. |

The application is software-review evidence, not medical validation or an
official PTB-XL evaluation. The demo excludes PTB-XL validation fold 9 and test
fold 10 and does not access AETHER's frozen scientific splits. Case screens
display official-source provenance and the AETHER-derived-label boundary.

The local HAPI FHIR representation and WSO2 Streamable HTTP MCP traffic are
real software/protocol operations over PTB-XL-derived metadata. The controlled
AETHER attack occurs after clean MCP retrieval and does not alter HAPI.
Deterministic agents are rules, not model reasoning. This configuration has no
clinical validation.
