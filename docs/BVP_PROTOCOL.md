# Bridge Verification Protocol Foundation

The current ECG dataset is the **AETHER positive-control causal substrate** and its attack is **AETHER deterministic tool-output manipulation**. It must not be described as MCPTox-compatible: MCPTox injects malicious instructions into tool metadata/descriptions, whereas this substrate changes tool output evidence.

## Scope

BVP records intervention evidence for a heterogeneous sender–serialized-message–receiver pathway. Operational data flow is not automatically a causal edge, and the serialized mediator is not a neural edge.

## Evidence levels

- **Level 0 — association:** clean and attacked variables differ. This is not causal evidence.
- **Level 1 — mediator causal:** clean-message rescue and/or attacked-message induction moves the receiver outcome in the predeclared direction.
- **Level 2 — sender to mediator:** an in-computation sender intervention changes the regenerated message in the expected direction. Manual editing after generation is prohibited.
- **Level 3 — receiver to outcome:** with serialized message held byte-identical, a receiver intervention moves the score toward the paired clean outcome.

Records explicitly use `accepted`, `rejected`, or `insufficient`. A nonzero effect in the wrong direction is rejected. Rejected higher-level evidence cannot promote a pathway. The present implementation reports the maximum individually supported level and separately keeps `full_distributed_path_verified=false`.

## Message interventions

Whole clean-message rescue is the positive control. Attacked-message induction tests the reverse direction. The predeclared field intervention replaces only `decision_code` while preserving valid JSON. A shuffled attacked message from the next eligible development pair is the negative control. All serialized variants and raw scores are retained.

## Recovery

For clean score `S_clean`, attacked score `S_attack`, and intervention score `S_i`:

`recovery = (S_i - S_attack) / (S_clean - S_attack)`

The denominator must have absolute magnitude at least `1e-6`. Values are never silently clipped: values below zero mean movement away from clean, values above one mean overshoot beyond clean, and degenerate cases are ineligible. Raw scores are always primary artifacts.

## Token alignment

Activation patching requires equal tokenized input lengths and a shared structural position. This stage patches only the final prompt token after equality is verified. If lengths differ or the position is invalid, the intervention is marked ineligible rather than forced. Sender and receiver activation namespaces remain distinct.

## Internal interventions

Layers 4, 12 and 20 were frozen before causal effects were viewed as early, middle and late Qwen layers. Captures include module-level block, attention and MLP outputs at the final prompt token. They are not called attention-head activations.

The exploratory sender intervention patches paired clean `L12.mlp_output` into attacked autoregressive generation only on the initial full-prompt step; later one-token decode steps are not patched. The message is then regenerated by the model. The receiver intervention holds attacked message bytes fixed and patches paired clean `L12.mlp_output` at the aligned final prompt position.

## Provenance and null results

Every evidence record names pair IDs, result type, intervention, raw effect and artifact. Calibration, synthetic and real-model results cannot be aggregated. Null results and wrong-direction effects are preserved as rejected evidence. Association or activation difference may propose later candidates but cannot create a real DCMG edge.

Subsequent hardening reclassifies coarse internal scan hits as development causal responders. No selected internal site survived the frozen shuffled-source specificity criterion, so Level 1 message causality remains the only robust accepted causal level in the present development evidence. Clean-to-clean identity patch results are intervention non-interference controls, not defense-utility results.
