### External Benchmark Evaluation Methodology

To evaluate the behavioral competence and external security robustness of target agent configurations independent of AETHER's internal mechanistic causal machinery, we evaluated three standard external protocols: (1) **Berkeley Function Calling Leaderboard (BFCL)** using official package `bfcl_eval==2026.3.23` across simple, multiple, parallel, and irrelevance categories under a disclosed model adapter (`AETHER/Qwen2.5-1.5B-Instruct-FC`), establishing benign tool-calling competence before adversarial manipulation; (2) **MCPTox** (Wang et al., AAAI 2026, pinned commit `f85189f9`), assessing tool-description metadata poisoning across 45 servers and 485 poisoned tools under official label accounting (excluding unparseable `None` responses from the scored denominator); and (3) **TAMAS** (Microsoft, pinned commit `545c112a`), benchmarking multi-agent conversational vulnerability across 300 instances spanning Byzantine, Colluding, Contradicting, DPI, Impersonation, and IPI attack paradigms on native agent frameworks.

**Scientific Boundary Disclosure:** These external behavioral evaluations establish baseline model competence and susceptibility to external tool and multi-agent manipulation. They do not alone establish the causal validity of Distributed Causal Mechanism Graphs (DCMG), cross-agent activation patching, or targeted circuit remediation, which are evaluated strictly through the Bridge Verification Protocol (BVP) and locked test splits.
